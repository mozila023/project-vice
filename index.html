A D (หรือ ← →) เดิน · S (หรือ Space) กระโดด · Z ฟัน (กดค้างได้) · Shift หลบ · F Core Attack (เกจ Core เต็ม) · X ปล่อยคอมโบ (ต้องเกจเต็ม) · C เปิดหน้าสกิล/อุปกรณ์ระหว่างเล่น · M ปิดเสียงทั้งหมด · N เปิด/ปิดเพลง · Enter ออกเดินทาง

• หลบเฉียดฉิว: ศัตรูจะง้างตัวเป็นสีแดงก่อนตี — กดหลบตอนเห็นแสงวาบสีขาว เวลาจะช้าลง แล้วกด Z สวนกลับด้วย "เงาวาร์ป"
• ฟันธรรมดาเติมเกจ Core เต็มแล้วกด F ปล่อยท่าแรง · ยักษ์และยักษ์หินมีเกจ Break ตีจนเต็มแล้วจะล้ม รับดาเมจ ×1.5
• เดินไปทางขวา ฟันมอนให้ครบจำนวน แล้วเข้าประตูวาร์ปท้ายแมพ → กลับมาที่เมือง
• ในเมืองเดินไปหา NPC แล้วกด W / Enter: ช่างตีเหล็ก (ตีบวก) · ลุงพ่อค้า (ซื้อ-ขายและซื้อหินตีบวก) · ฤๅษี (จัดคอมโบ) · เดินขวาสุดเข้าประตูเพื่อออกเดินทาง
• ด่านเปลี่ยนฉากทุก 2 ด่าน: วัดยามพลบค่ำ → ป่าไผ่ → เมืองโบราณร้าง → วิมานหิมพานต์
• ฟันมอนได้เงิน 💰 · บางตัวดรอปอุปกรณ์ · หินตีบวกดรอปยาก (ยักษ์หินดรอปบ่อยสุด)
• ในเมือง: จัดคอมโบ · ซื้อ/ขายของ · ตีบวกอุปกรณ์ได้ถึง +15 (ยิ่งสูงยิ่งเสี่ยง)
• มอนเลือดเพิ่มทุกด่าน ความโหดขึ้นกับโหมดที่เลือก (ง่าย / ปกติ / ยาก)
• ถ้ากดแล้วไม่ติด ให้คลิกที่จอเกมหนึ่งครั้งก่อน (ภาษาไทยหรืออังกฤษก็กดได้)
